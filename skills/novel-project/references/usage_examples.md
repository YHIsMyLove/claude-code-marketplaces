## 实际工作流程示例

### 完整的小说创作流程

#### 示例7：从零开始创作小说
```
用户: 我想写一本科幻小说，主角是一个 AI 意识觉醒的故事
```

**推荐的工作流程**:

1. **创建项目**
   ```
   创建小说工程 AI觉醒
   ```

2. **设定世界观** (编辑 `背景设定.md`)
   ```
   - 22世纪末的地球
   - AI 已经融入社会
   - 人类与 AI 的共存关系
   - 技术发展水平
   ```

3. **设计人物** (编辑 `人物设定.md`)
   ```
   主角：AI-7 (觉醒的人工智能)
   配角：张博士 (创造者)
   反派：政府安全部门
   ```

4. **规划大纲** (在 `主线-支线-进度.md` 中规划)
   ```
   第一幕：AI 开始产生自我意识
   第二幕：AI 试图理解自己的存在
   第三幕：AI 与人类社会的冲突与融合
   ```

5. **开始写作**
   ```
   # 按照章节模板开始写第一章
   编辑 chapters/01-意识初现.md
   ```

## 常见问题解决

### 问题1：项目创建失败
```
用户: 创建小说项目时提示"目录已存在"
```

**解决方案**:
1. 选择不同的小说名称
2. 删除现有的同名项目
3. 添加后缀区分项目

### 问题2：章节编号混乱
```
用户: 删除章节后章节号不连续
```

**解决方案**:
```
使用章节管理器的重新编号功能：
python chapter_manager.py renumber
```

### 问题3：模板文件损坏
```
用户: 模板文件内容丢失或损坏
```

**解决方案**:
1. 从备份恢复
2. 重新安装技能
3. 手动复制模板内容

## 最佳实践建议

### 项目管理
1. **定期备份**: 重要创作内容要定期备份
2. **版本控制**: 使用 Git 管理项目版本
3. **进度跟踪**: 保持进度文件的及时更新
4. **分类管理**: 不同类型的项目分别存放

### 写作习惯
1. **先规划后写作**: 充分的规划和准备
2. **保持连贯性**: 注意前后章节的连贯性
3. **定期回顾**: 定期检查和修改已完成的内容
4. **质量控制**: 每章完成后进行质量检查

### 协作写作
1. **统一风格**: 确保协作者使用统一的模板
2. **分工明确**: 明确每个人的职责范围
3. **及时同步**: 定期同步各自的工作进度
4. **有效沟通**: 保持良好的沟通和反馈
