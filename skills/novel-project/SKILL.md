# Novel Project 技能

## 概述

Novel Project 是一个专门为小说创作者设计的技能，能够快速创建标准化的小说工程目录结构，包含完整的写作模板和章节管理功能。

## 何时使用

- 开始新的小说创作项目时
- 需要规范化管理小说素材和章节时
- 希望使用专业模板提高写作效率时
- 需要系统化管理人物设定和背景资料时

## 前置条件

- Python 3.6 或更高版本
- 足够的磁盘空间用于创建项目文件
- 当前目录的写入权限

## 使用方法

### 基本用法
```
请使用 novel-project 技能创建一个名为"小说名称"的小说工程
```

### 示例
```
创建小说工程 三国演义
```
这将创建一个名为 `三国演义_project` 的文件夹，包含完整的小说写作结构。

### 章节管理
```
为新小说"三国演义"添加第三章
重命名"三国演义"的第一章为"桃园三结义"
列出"三国演义"的所有章节
```

## 执行流程

1. **验证输入**: 检查小说名称的合法性和目录权限
2. **创建目录**: 生成标准化的项目目录结构
3. **生成模板**: 创建包含写作指导的 Markdown 模板文件
4. **初始化配置**: 生成项目配置和说明文件
5. **错误处理**: 提供详细的错误信息和解决建议

## 文件结构

### 技能文件结构
```
novel-project/
├── SKILL.md                     # 技能定义文件
├── scripts/
│   ├── create_novel.py         # 主要创建脚本
```

## 错误处理

### 常见错误和解决方案

1. **目录已存在错误**
   - 错误信息：`目标目录已存在`
   - 解决方案：选择不同的小说名称或删除现有目录

2. **权限不足错误**
   - 错误信息：`没有写入权限`
   - 解决方案：切换到有写入权限的目录

3. **无效名称错误**
   - 错误信息：`小说名称包含无效字符`
   - 解决方案：使用字母、数字和中文，避免特殊字符

4. **Python 版本错误**
   - 错误信息：`需要 Python 3.6 或更高版本`
   - 解决方案：升级 Python 版本

## 自定义选项

### 模板自定义
可以通过修改 `assets/templates/` 目录下的文件来自定义模板内容。

### 配置自定义
通过编辑 `assets/config.json` 文件可以调整技能的默认行为。

## 最佳实践

1. **命名规范**: 使用有意义的小说名称，便于项目识别
2. **定期备份**: 定期备份重要的写作内容
3. **版本控制**: 考虑使用 Git 管理小说项目
4. **模板定制**: 根据个人写作习惯调整模板内容

## 故障排除

如果遇到问题，请检查：
1. Python 版本是否符合要求
2. 当前目录是否有写入权限
3. 小说名称是否包含特殊字符
4. 磁盘空间是否充足
