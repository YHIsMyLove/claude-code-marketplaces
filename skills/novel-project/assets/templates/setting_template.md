## 设定一致性检查

### 内部逻辑
- [ ] 设定之间是否存在矛盾
- [ ] 社会发展是否合理
- [ ] 技术水平是否一致
- [ ] 地理环境是否合理

### 外部关联
- [ ] 设定是否服务主题
- [ ] 是否便于情节展开
- [ ] 人物是否适应这个设定
- [ ] 读者是否容易理解

### 独特性
- [ ] 与同类作品是否有区别
- [ ] 是否有自己的特色
- [ ] 是否有吸引力
- [ ] 是否有发展空间

---

**使用提示**:
1. 根据小说类型选择相关的设定内容
2. 保持设定的一致性和合理性
3. 设定应该为故事服务，不要过度设定
4. 在写作过程中可以逐步完善设定
5. 注意设定与主题、人物的关联性
